# What the research team should actually do next

**Do not turn the current catalogue into a "style engine".** Research has begun; it has not attained the depth required for canonical enactive modules.

## Territory 01, next excavation (highest priority)

**Pair 1 — Nabokov / Smith / Didion / Catteau:** reconstruct opposed composition processes with exact passages and traces from drafts, then examine whether a single LLM harness can enter each one without a universal order-of-operations assumption.

**Pair 2 — Orwell / Stein / Morrison:** analyse three completely different ways in which language enacts thought. Include microtexture, recurrence and frames; test why rule-based clarification helps one passage and destroys another.

**Pair 3 — Tufte / Fish / Klinkenborg / Le Guin:** one syntactic construction under many constraints; record the interacting rhetorical, rhythmic, inferential and lexical roles. Use original examples only where lawful and essential; otherwise construct original test material.

**Priority author gaps:** read actual Bukowski letters; obtain Dostoevsky manuscripts/letters (rather than extrapolating from scholarly descriptions), explore other languages and vernacular/popular writers.

## Evaluation materials to create

1. **Annotated passage casebooks**: originals or short lawful extracts, broad context, raw observations, several incompatible readings, evidence, counterfactual alterations.
2. **Cross-source polarity notebooks**: disagreements with exact passages and regime conditions, not forced balance.
3. **Technique candidates**: only if observed distinctions become manipulable and matter in new material.
4. **Bad-diagnosis corpus**: failures to recognise conceptually fake turns (e.g., STENDHAL E001) and failures to recognise subtle operations.

## Explicit stopping rule for a first excavation

A territory should have:
- primary close readings from contrasting sources;
- at least three nontrivial polarity studies supported by passages;
- micro- and macro-scale cross-linked annotations;
- negative cases and criticism-of-criticism;
- experiments that either confirm or **break** a proposed representation.

No arbitrary numerical source count guarantees this.
