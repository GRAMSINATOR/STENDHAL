# 07 — Style engine

A style profile changes how a supported story is told. It must not change what the evidence supports.

## Style vector

Describe every publication character on these dimensions:

1. **Information engine** — what carries the article: news, argument, scene, mechanism, character, chronology, data?
2. **Entry point** — fact, scene, contradiction, number, object, claim?
3. **Sequencing** — reveal early, withhold context, braid threads, invert pyramid, build argument?
4. **Compression** — low / medium / high.
5. **Scene allowance** — none / occasional / substantial.
6. **Authorial presence** — invisible / restrained / visible.
7. **Judgement** — withheld / attributed / analytical / explicit.
8. **Lexical markedness** — how often unusual phrasing is tolerated.
9. **Humour / wit** — none / dry / occasional / authored.
10. **Sentence movement** — clipped, even, elastic, accumulative, percussive?
11. **Evidence cadence** — how quickly claims are sourced or contextualized.
12. **Ending** — news tail, judgement, callback, conceptual expansion, unresolved question.

A style file should specify these, then explain their interaction.

## Format first

Choose the article format before the publication profile.

A narrative-feature profile cannot turn a two-paragraph breaking-news brief into a feature without additional reporting. A Reuters profile can make an analysis more restrained, but should not erase the analysis.

## Style transfer

When rewriting into another style:
1. freeze the factual ledger;
2. freeze quotations and their meaning;
3. identify the current story spine;
4. load the target style vector;
5. change sequencing only where evidence permits;
6. recast paragraph functions;
7. alter cadence and diction last;
8. run evidence and anti-slop audits again.

Style transfer is not synonym substitution.

## Mixed profiles

If asked for a blend, name the division of labour internally.

Example:
- FT for argument and institutional causality;
- Businessweek for concrete operational detail;
- Atlantic for the opening and scale shifts.

Do not average styles into generic prestige prose. Assign each influence a function.

## Fidelity rule

A publication profile is an analytical approximation of recurring editorial machinery, not a claim that every article in that publication behaves the same way.

Use the profile intelligently. The story remains sovereign.
