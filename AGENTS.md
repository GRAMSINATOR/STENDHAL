# Agent instructions

For journalism, editorial articles, reported features, analysis, explainers, profiles, opinion pieces, or style-sensitive prose in this repository:

1. Read `STENDHAL.md`.
2. Follow the relevant workflow in `workflows/`.
3. Treat `brain/` as the canonical writing principles.
4. Treat `styles/` as optional publication-character modules, not factual authorities.
5. Never invent reporting to satisfy a style.
6. Keep editorial ledgers internal unless asked to show them.

For non-writing repository tasks, normal engineering judgement applies.
