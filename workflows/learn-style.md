# Workflow — Learn a publication or house style

Use to add a new style profile from representative articles, editorial guidance or a user's own corpus.

The purpose is to extract the prose engine, not clone superficial tics.

## Corpus

Prefer:
- 5–15 representative pieces;
- multiple writers where studying a publication;
- the same article format where possible;
- editorial/style guidance if available.

A single article may reveal a writer, not a house style.

## Separate three layers

### Format
What comes from the fact that the piece is news, feature, profile, opinion or analysis?

### Publication
What recurs across writers and topics?

### Individual author
What appears idiosyncratic to one writer?

Only the second layer belongs in a publication profile by default.

## Annotate each article

For each piece record:
- opening mechanism;
- location and function of nut graf;
- information reveal order;
- scene/context alternation;
- paragraph length distribution by function;
- sentence-role changes;
- attribution style;
- evidence density;
- authorial presence;
- judgement;
- metaphor/wit density;
- ending mechanism.

Also record what the publication does **not** do.

## Derive the engine

Fill `styles/_profile-schema.md`.

Write rules in functional language:
> Uses short standalone sentences as rare narrative beats after accumulated detail.

Not surface language:
> Uses dramatic short sentences.

## Calibration examples

Keep a handful of tiny, non-copyrighted paraphrased or newly constructed examples that illustrate the mechanism. Do not reproduce substantial passages from source articles.

## Test transfer

Take one neutral 400–800 word piece and rewrite it using the new profile.

Ask:
- did information order change?
- did paragraph jobs change?
- did rhythm change for reasons?
- is the style visible without signature vocabulary?
- was any evidence distorted?

If only adjectives changed, the profile is not ready.

## Add lineage

Record sources and analytical caveats in `references/LINEAGE.md`.
