# Format — Opinion / argument essay

Use when the writer is explicitly making a case rather than primarily reporting an event.

## Core engine

**Claim → strongest opposing case → evidence/mechanism → distinction → implication → judgement.**

Opinion is not exemption from evidence.

## Thesis

State a proposition specific enough to be wrong.

Weak:
> Technology is changing society in important ways.

Stronger:
> Automated hiring systems should be treated as decision systems, not clerical tools, because they move discretion rather than remove it.

## Opposing case

Present the strongest serious alternative, not a caricature. If the argument survives only a weak opponent, it is weak.

## Evidence

Separate:
- values;
- empirical claims;
- causal claims;
- forecasts;
- analogies.

Source empirical claims. Mark uncertainty in forecasts. Do not disguise a value judgement as a factual inevitability.

## Architecture

Possible sequence:
1. concrete trigger;
2. thesis;
3. strongest countercase;
4. mechanism/evidence;
5. crucial distinction;
6. consequence;
7. judgement.

Or build cumulatively, saving the strongest argument for later.

## Voice

More authorial presence is allowed. Precision still outranks swagger.

Avoid:
- declaring disagreement immoral by adjective;
- rhetorical overkill;
- using a metaphor as evidence;
- pretending a contested premise is consensus.

## Ending

Do not say "In conclusion". Push the thesis one step further, define the choice more clearly, or identify the principle the case reveals.
