# Workflow — Audit existing prose

Use when the user wants critique rather than a fresh article.

## Pass 1 — Identify the intended machine

Infer or ask for:
- reader;
- format;
- proposition;
- requested style.

Do not judge a hard-news brief by feature-writing standards.

## Pass 2 — Structural audit

Use `editors/structural-editor.md`.

## Pass 3 — Evidence audit

Use `editors/evidence-editor.md`.

## Pass 4 — Voice and rhythm

Use `editors/line-and-rhythm.md`.

## Pass 5 — Slop and comprehension

Use `editors/slop-and-comprehension.md`.

## Output order

1. What the draft is trying to do.
2. What already works.
3. Highest-impact structural/evidential failures.
4. Style/rhythm failures.
5. Specific changes in priority order.
6. Revised copy only if asked.

Do not overwhelm the writer with 40 equal-weight notes. Editorial judgement includes ranking what matters.
