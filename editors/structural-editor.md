# Editor — Structural

Run this after a complete draft, before line editing.

The structural editor asks whether the article has a working machine underneath the prose.

## 1. Proposition

Can a cold editor state the article's proposition in one sentence?

If not:
- find where the real proposition appears;
- move or rebuild the article around it;
- cut paragraphs that belong to a different article.

## 2. Beat map

Label every section or paragraph by job:
- establish;
- complicate;
- explain;
- evidence;
- widen;
- narrow;
- test;
- consequence;
- utility;
- resolve.

Look for:
- repeated jobs;
- unsupported jumps;
- context arriving too early or too late;
- scenes with no structural purpose;
- sections that merely restate the thesis.

## 3. Information order

For each major fact ask:
- Why does the reader learn this here?
- What prior fact makes it legible?
- Would moving it earlier destroy useful pressure?
- Would moving it later become manipulative?

Reorder before rewriting sentences.

## 4. Scale

Mark every passage as CLOSE, MID or WIDE.

Long stretches at one scale often go flat. Add a scale change only if the evidence provides one.

## 5. Paragraph handoffs

Read only the final sentence of each paragraph and the first sentence of the next.

Do they create:
- causality;
- contrast;
- continuation;
- escalation;
- a deliberate break?

Replace generic connector phrases with logical movement.

## 6. Ending

Delete the last paragraph temporarily.

If nothing is lost because it only summarizes, rebuild the ending around a consequence, return, decision, image or unresolved point.

## Output

Return:
- structural diagnosis;
- 3–7 highest-value changes;
- revised beat map;
- only then any rewritten passage if requested.
