# Experiment 002 — First compositional field, before prose

**State:** candidate representation prepared; no controlled test run, no proof of literary quality.

## Research question

Can we represent *multiple coexisting functions and nonlocal dependencies* without committing to sentences, and manipulate the representation in ways that suggest genuinely different creative pathways?

## Locked material

Reuse the fictional library facts from Experiment 001, **only** to control source variables. Do not treat the data points as obligatory opening or the "opposite trends" as an intrinsically meaningful paradox.

## Candidate field

[composition-field.json](composition-field.json) is an inspectable example containing a handful of **pre-verbal** compositional units, functional tracks spanning several units, source constraints and creative perturbation candidates.

It is neither a prose draft nor a validated mathematical field. Its purpose is to make architectural assumptions visible and debatable.

## No-prose gate

Before any sentence drafting, audit:
- Which units are true facts, creative proposals or explicit hypotheses?
- Does any proposed drama depend on a fake conflict?
- Which tracks operate beyond single units? Can a unit participate in more than one?
- What has deliberately been left unsaid or unresolved?
- What changes if a unit is moved, removed or replaced?
- Are alternative imaginative sources available other than the obvious statistics?
- What knowledge would need to be added to responsibly realise this composition as reported nonfiction?
- What if the commission's most suitable form is **not an essay**?

## Next empirical stage (not yet run)

Implement operations on the candidate graph, compare several different topologies before language realisation, and record qualitative criticism. Only after the representation survives that test should surface generation be attempted.

Critical design rule: the *field must be constructed first*. Retrofitting an abstract plan to an already-written paragraph would not test our actual hypothesis.
