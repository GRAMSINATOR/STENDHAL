# Format — Profile

Use when a person is the best route into a larger set of ideas, institutions, contradictions or consequences.

## Core engine

**Person in action → governing contradiction → history/context → tests of character/claim → wider meaning.**

A profile is not a résumé with scenery.

## Find the contradiction

Ask:
- What does the subject say they are trying to do?
- What do they actually spend time doing?
- What do admirers see?
- What do critics see?
- Which past event explains the current posture?
- Where does the subject's self-conception collide with the system around them?

Do not manufacture psychological diagnoses.

## Opening

Prefer action over biography:
- a meeting;
- a choice;
- an interaction;
- a habit;
- a moment that contains the central contradiction.

Then widen.

## Reporting

A serious profile should distinguish:
- subject's account;
- independent record;
- colleagues/allies;
- critics/opponents;
- reporter observation.

Do not let access become evidence.

## Description

Choose details that reveal behaviour, status, environment, attention or contradiction. Avoid decorative physical description with no interpretive value.

## Chronology

Do not default to birth → school → career. Use chronology where it explains the current person.

## Voice

The writer may be observant and interpretive, but should not claim access to motives or internal states that reporting cannot establish.

## Ending

End where person and larger system meet: a decision, unresolved contradiction, repeated habit, or image that now carries the profile's proposition.
