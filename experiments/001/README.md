# Experiment 001 — Three writing experiences from one fact pack

**Status: completed exploratory self-pilot, not validated comparative study.** Date: 2026-10-11.

## Test question

Can one set of fixed facts yield **genuinely distinct compositional mechanisms** across writing regimes, and can we deliberately alter those mechanisms without corrupting factual commitments?

The pilot tests enacted differentiation, fine-grained revision, retrospective extraction, and adversarial editorial critique. It is meant to expose design requirements, not prove improvement.

## What was actually done

One model authored the three initial texts from the same fictional facts, performed three local interventions, and retrospectively analysed the pieces through several lenses. The texts and assessments are saved verbatim.

**Crucial limitation:** the exercise did **not** use separate blind model runs, independent readers, externally tested quality scores, or an actual unaided-vs-instrumented model comparison. Retrospective extraction is self-review, not independent replication. Any claims of causal improvement would therefore be unsupported.

## Immediate provisional finding

The prose differs in information order and cadence, but all three pieces gravitate toward the same interpretation: visits and borrowing measure different aspects of library use. The exploratory literary version also remains very explanatory. This is a **potential architectural failure in genuine regime differentiation**, not something to conceal behind descriptions of 'different voices'.

## Experiment discipline

This project must distinguish facts, interpretations, aesthetic preferences, candidate mechanisms and experimentally demonstrated abilities. Do not promote findings into universal writing instructions on the basis of this pilot.
